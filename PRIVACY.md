# Privacy Policy

GitHub Helper is a browser extension that adds small quality-of-life tweaks to
github.com.

## Data collection

GitHub Helper does not collect, store, or transmit any data. It has no backend,
no analytics, and no telemetry.

## What the extension does

The extension runs a content script only on pages under `https://github.com`.
The script reads the current page URL to decide which repository you are
viewing and adds UI elements, such as buttons, to the page. It does not read
page content beyond what is needed to place those elements, and it does not
send anything anywhere.

## Permissions

The extension requests no browser permissions beyond running on github.com.

## Third parties

No data is shared with third parties because no data is collected.

## Changes

If this policy changes, the update will be published in this file in the
extension's source repository.
